# Minemp3

Minecraft 里的随身听。在游戏内搜索、播放网易云音乐，支持歌单、每日推荐、专辑封面和环境音效。

> 仅供个人学习交流，音乐版权归网易云及各版权方所有。

## 特性

- **游戏内播放**：边下边播，不落盘，不占用额外磁盘
- **搜索 / 我喜欢的音乐 / 每日推荐**：点任意一首，整个列表自动成为播放队列
- **播放队列**：列表循环 / 单曲循环 / 随机，播完自动接下一首，失败自动跳过
- **专辑封面**：异步加载 32×32 缩略图
- **环境音效**：水下低通 + 矿洞混响，切换平滑无爆音
- **暂停 / 进度 / 音量 / 淡入淡出**：交叉淡化切歌，无爆音
- **扫码登录**：游戏内生成二维码，手机网易云 App 扫一下

## 环境要求

| 项目 | 版本 |
|---|---|
| Minecraft | 26.3 |
| Fabric Loader | ≥ 0.20.1 |
| Fabric API | 0.165.2+26.3 |

## 安装

1. 装好 Fabric Loader 和 Fabric API
2. 把 `handheld-music-player-0.1.0.jar` 放进 `.minecraft/mods`
3. 启动游戏

mp3 解码库已经内嵌在 jar 里，不需要额外安装。

## 合成

工作台 3×3：

```
铁锭   红石   铁锭
铁锭   钻石   铁锭
铁锭   铁锭   铁锭
```

也可以直接 `/give @s handheldmusic:handheld_player`。

## 使用

**右键随身听打开播放器。** 不用的时候屏幕上不显示任何东西。

| 按钮 | 作用 |
|---|---|
| 播放 / 暂停 | 空闲时按会跳到搜索页 |
| 停止 | 淡出停止，队列保留 |
| 上一首 / 下一首 | 队列内前后切换 |
| 搜索 | 输入歌名或歌手，点结果直接播 |
| 歌单 | 我喜欢的音乐（红心） |
| 每日 | 每日推荐 |
| 循环 | 列表循环 → 单曲循环 → 随机 |
| 低通 | 600Hz 低通 |
| 音量 - / + | 也可以用鼠标滚轮 |

进度条下方中间的 `3/30` 是队列位置。状态文字右边的三根小竖条是播放律动，暂停时压平。

## 登录

不登录也能匿名播放大部分非 VIP 曲目。登录后可用红心歌单、每日推荐和 320kbps 音质。

### 方式一：粘贴 cookie（推荐）

1. 浏览器登录 [music.163.com](https://music.163.com)
2. F12 → Application → Cookies → 复制 `MUSIC_U` 的值
3. 游戏里输入 `/hmpaste`

`/hmpaste` 直接读系统剪贴板，**不要**用 `/hmcookie` 手动粘贴——聊天框有 256 字符上限，而 `MUSIC_U` 有 800+ 字符，会被静默截断。

### 方式二：扫码

输入 `/hmqr`，用手机网易云 App 扫码。

部分账号会被网易风控拦截（返回 8821），此时请改用方式一。

## 命令

| 命令 | 作用 |
|---|---|
| `/hmplay <关键词>` | 按关键词播放 |
| `/hmpause` | 暂停 / 继续 |
| `/hmnext` / `/hmprev` | 下一首 / 上一首 |
| `/hmmode` | 切换播放模式 |
| `/hmstop` | 停止 |
| `/hmstatus` | 播放 + 登录状态 |
| `/hmqr` | 扫码登录 |
| `/hmpaste` | 从剪贴板读 cookie |
| `/hmlogin` / `/hmlogout` | 查看登录状态 / 退出登录 |
| `/hmenv <模式>` | 强制环境音效：`outdoor` / `indoor` / `underwater` / `auto` |

## 已知限制

- **不能拖进度**：流式 mp3 的 seek 需要按字节偏移重新请求
- **队列不落盘**：重启游戏后清空
- **只有中文界面**：还没做多语言

## 构建

需要 JDK 25。

```bash
./gradlew build
```

产物在 `build/libs/handheld-music-player-0.1.0.jar`。
